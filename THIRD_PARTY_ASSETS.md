# Third-party assets

Brush tips and paper grain textures shipped in `public/brushes/` come from the
sources below. They are generated by `npm run brushes`
(`tools/convert-brushes.ts`), which downloads each archive (or reads a file
placed by hand in `.brush-cache/` when there is no direct download URL),
verifies its sha256, and converts the files. Each source folder contains the upstream
license text and a README with provenance. `public/brushes/manifest.json` maps
every asset to its source and upstream file.

| Folder | Source | Author | License |
|---|---|---|---|
| `public/brushes/revoy-2025-01/` | [Krita brushes 2025-01 bundle](https://www.davidrevoy.com/article1060/krita-brushes-2025-01-bundle/show) | David Revoy | CC0-1.0 |
| `public/brushes/oga-grunge/` | [~100 grunge brushstrokes and splatters set](https://opengameart.org/node/119417) | Dino0040 | CC0-1.0 |
| `public/brushes/rav89-digital-painting/` | [Photoshop Brushes for digital painting](https://myphotoshopbrushes.com/resources/3883/photoshop-brushes-for-digital-painting) | [RaV89](https://www.deviantart.com/rav89) | [MyPhotoshopBrushes Free for Commercial Use](https://myphotoshopbrushes.com/licenses#free-commercial) |

CC0 requires no attribution; credit is given anyway. The RaV89 license allows
personal and commercial use without attribution but forbids redistributing or
reselling the brush files themselves, so the original `.abr` is not in the
repository or the build (it lives in the git-ignored `.brush-cache/`), Zketch
only ships tips converted for its own brush engine, and must not offer them as
downloadable brushes. Photoshop stock tips and patterns bundled inside that
`.abr` are not used. Assets are served as
separate files and are not part of the MIT-licensed source code bundle.
